# @kilocode/react-native-ssh

An SSH client for React Native and Expo, with the protocol implementation in
Rust ([russh](https://crates.io/crates/russh)) and the Kotlin/Swift bridge
generated by [uniffi](https://mozilla.github.io/uniffi-rs/).

**Status: pre-release.** Only the native pipeline is wired up so far: the Rust
core exposes two functions, the uniffi bindings are generated for both
platforms, and the Expo module surfaces them to TypeScript. Connecting and
authenticating, the terminal views, SFTP and port forwarding land in later
releases.

## Layout

| Path | Contents |
| --- | --- |
| `rust/ssh-core` | The Rust library (`core_version`, `generate_ed25519_key`) |
| `rust/uniffi-bindgen` | Bindings generator binary used by the build scripts |
| `android/`, `ios/` | The Expo module and its native build files |
| `src/` | TypeScript API |
| `example/` | Expo app that prints the core version and a generated key |
| `scripts/` | Native build scripts |

## Building

Generated code is not committed. Run the script for the platform you target
before building the module or the example app:

```sh
scripts/build-android.sh   # libssh_core.so + Kotlin bindings (needs the Android NDK)
scripts/build-ios.sh       # SshCore.xcframework + Swift bindings (needs macOS and Xcode)
```

Android output lands in `android/src/main/jniLibs` and
`android/src/main/java/ai/kilo/reactnativessh/uniffi`; iOS output lands in
`ios/Frameworks` and `ios/Generated`.

## Development

```sh
npm install
npm run build                       # TypeScript -> build/
cd example && npm install
npx expo prebuild --platform android
npx expo run:android
```
